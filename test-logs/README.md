# PILUITUS — PAPER test logs

This directory is reserved for diagnostic files from local PAPER-mode test runs.

## What to upload

For each run, add the following files when available:

- `run_*.log` or `session_*.log` — full session log;
- `diagnostic_*.log` — diagnostic counters and periodic status;
- `errors_log_*.log` — errors and tracebacks;
- optional trade/export reports for the same run.

## Naming and grouping

Keep the original filenames generated by PILUITUS. Do not overwrite logs from earlier runs.

If convenient, create a subdirectory per run using its run ID, for example:

`test-logs/20261106_130617_12360_8ff4975c/`

All files in one run folder should belong to the same run ID.

## Notes

- Upload only logs needed for debugging; redact API tokens, account identifiers, and other secrets.
- Do not upload virtual environments, caches, databases, or private key files.
- Keep source code and test logs separate.
